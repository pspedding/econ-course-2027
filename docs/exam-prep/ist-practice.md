## 💡 Key Worked Examples

### Q5 — New Commuter Surplus (Half-Rule)
New commuters travel 1 million extra trips. Their surplus = ½ × (time saving per trip) × (new trips):
- Time saving = 1.5 − 0.5 = 1 hour/trip at $20/hr = **$20 value/trip**
- New trips = 3m − 2m = **1 million**
- New commuter CS = ½ × $20 × 1,000,000 = **$10 million** → Answer: **E**

### Q12 — Elasticity Calculation
ε = (dQ/dP) × (P/Q) = −2 × (P/Q) = −0.25
→ −2P/Q = −0.25 → P/Q = 0.125 → P = 0.125Q
Substitute into demand: Q = 100 − 2(0.125Q) = 100 − 0.25Q
1.25Q = 100 → **Q = 80** → Answer: **C**

### Q18 — AVC Calculation
TC = 5 + q + q²; Variable cost = TC − Fixed cost = q + q²
At q=5: VC = 5 + 25 = 30; **AVC = 30/5 = 6** → Answer: **E**

### Q19 — Profit Maximisation
P = MC: 6 = 2 + 2q → q = 2
TR = 6 × 2 = 12; TC = 6 + 2(2) + 2² = 6 + 4 + 4 = 14
**Profit = 12 − 14 = −2** → Answer: **A**
